delay

suspend fun delay(reference: Instant, clock: Clock, maxTick: Duration? = null): Boolean(source)

Waits the required amount of time before this TickingValue needs recalculation, depending on the current time provided by clock.

If the current time is past the time for recomputation, no amount of time is waited. Same when nextTick is null.

Return

false if nextTick is null, true otherwise

Parameters

reference

the reference point used to calculate this value

clock

the clock used to determine the current time

maxTick

the maximum amount of to wait for a recomputation (as long as nextTick is not null). If null (the default), no max tick bound is applied.
